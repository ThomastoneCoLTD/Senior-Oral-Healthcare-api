## 수정과 배포 권고

1. API에 공유 키 헤더를 추가하되 기존 회수 본문은 일시 유지하고, 새 API 인스턴스 교체 완료를 확인합니다.
2. SOH_DID에 키 필수 인증과 서버 소유자 값 강제 적용을 배포합니다. health와 필요한 운영 조회 경로의 인증 정책을 명시합니다.
3. API의 개인키 전송·서비스 필수 검사·workflow 필수 검사·환경 설정을 제거합니다. 관리자 공개 주소와 사용자 지갑의 승인용 키 처리 계약은 유지합니다.
4. 리워드 역할 제한과 오류 마스킹은 관련 음성 테스트와 함께 별도 수정합니다. 인증 실패는 거래 제출 전 실패로 구분하고 타임아웃만으로 재전송하지 않습니다.
5. 소스 비밀값을 제거한 뒤 대구체인과 안전한 키 변경 절차를 확인합니다. 기존 지갑·잔액·승인·암호화 키는 임의 변경하지 않습니다.

위 수정은 이번 점검에서 실행하지 않았습니다. 조사 기록만 저장하며 운영 앱 재배포를 시작하지 않습니다. rollback 시 관리자 승인·거래 증명 점유·지갑 암호화 계약을 유지해야 합니다.
